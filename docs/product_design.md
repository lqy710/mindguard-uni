## 一、设计规范

### 1.1 配色方案

基于心理健康领域的专业配色研究，选择温暖、舒适、专业的配色方案。

#### 主色调

| 颜色名称 | 色值 | 用途 | 心理暗示 |
|---------|------|------|----------|
| **宁静蓝** | `#4A90A4` | 主品牌色、主要按钮、导航高亮 | 平静、信任、专业 |
| **温暖橙** | `#E8956F` | 强调色、CTA按钮、重要提示 | 温暖、关怀、积极 |
| **治愈绿** | `#7CB69D` | 成功状态、正向反馈、健康指标 | 成长、希望、治愈 |

#### 辅助色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| **深空蓝** | `#2C5F6E` | 标题文字、重要信息 |
| **柔和紫** | `#9B8AA6` | 装饰元素、次要强调 |
| **淡粉橙** | `#F5E6DC` | 卡片背景、温馨区域 |

#### 中性色

| 颜色名称 | 色值 | 用途 |
|---------|------|------|
| **深灰** | `#333333` | 正文文字 |
| **中灰** | `#666666` | 次要文字 |
| **浅灰** | `#999999` | 占位文字、禁用状态 |
| **边框灰** | `#E5E5E5` | 分割线、边框 |
| **背景灰** | `#F7F8FA` | 页面背景 |
| **纯白** | `#FFFFFF` | 卡片背景、输入框 |

#### 语义色

| 状态 | 色值 | 用途 |
|------|------|------|
| **成功** | `#52C41A` | 成功提示、完成状态 |
| **警告** | `#FAAD14` | 警告提示、注意事项 |
| **错误** | `#FF4D4F` | 错误提示、危险操作 |
| **信息** | `#1890FF` | 信息提示、帮助说明 |

#### 渐变色

```
主渐变：linear-gradient(135deg, #4A90A4 0%, #7CB69D 100%)
温暖渐变：linear-gradient(135deg, #E8956F 0%, #F5C4A1 100%)
背景渐变：linear-gradient(180deg, #F7F8FA 0%, #FFFFFF 100%)
```

### 1.2 字体规范

#### 字体家族

```css
/* 主字体 */
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', 'Helvetica Neue', sans-serif;

/* 数字字体 */
font-family: 'DIN Alternate', 'Roboto Mono', monospace;
```

#### 字体层级

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| H1 | 32px | Bold (700) | 1.25 | 页面主标题 |
| H2 | 24px | Semibold (600) | 1.33 | 区块标题 |
| H3 | 20px | Semibold (600) | 1.4 | 卡片标题 |
| H4 | 18px | Medium (500) | 1.44 | 小节标题 |
| Body-L | 16px | Regular (400) | 1.5 | 正文大字 |
| Body-M | 14px | Regular (400) | 1.5 | 正文标准 |
| Body-S | 12px | Regular (400) | 1.5 | 辅助文字 |
| Caption | 12px | Regular (400) | 1.33 | 标签、说明 |

### 1.3 间距规范

采用 8px 基础间距系统，确保视觉一致性。

#### 间距层级

| 名称 | 数值 | 用途 |
|------|------|------|
| xs | 4px | 紧凑元素间距 |
| sm | 8px | 相关元素间距 |
| md | 16px | 组件内部间距 |
| lg | 24px | 区块间距 |
| xl | 32px | 大区块间距 |
| xxl | 48px | 页面区域间距 |
| xxxl | 64px | 页面顶部间距 |

#### 页面边距

| 设备类型 | 页面边距 | 内容最大宽度 |
|----------|----------|--------------|
| 移动端 | 16px | 100% |
| 平板 | 32px | 768px |
| 桌面端 | 48px | 1200px |

---

### 1.4 圆角规范

| 名称 | 数值 | 用途 |
|------|------|------|
| 小圆角 | 4px | 标签、小按钮 |
| 中圆角 | 8px | 输入框、小卡片 |
| 大圆角 | 12px | 卡片、弹窗 |
| 超大圆角 | 16px | 大型容器 |
| 全圆角 | 999px | 胶囊按钮、头像 |

### 1.5 阴影规范

| 名称 | 样式 | 用途 |
|------|------|------|
| 轻阴影 | `0 2px 8px rgba(0, 0, 0, 0.06)` | 卡片悬浮 |
| 中阴影 | `0 4px 16px rgba(0, 0, 0, 0.08)` | 弹窗、下拉菜单 |
| 重阴影 | `0 8px 24px rgba(0, 0, 0, 0.12)` | 模态框 |
| 内阴影 | `inset 0 2px 4px rgba(0, 0, 0, 0.04)` | 输入框聚焦 |

### 1.6 图标规范

- **图标库**：使用 Phosphor Icons 或 Heroicons
- **尺寸**：16px / 20px / 24px / 32px
- **线宽**：1.5px
- **风格**：线性图标，圆角端点
- **颜色**：继承文字颜色或使用品牌色

### 1.7 组件规范

#### 1.7.1 按钮组件

**主要按钮（Primary）**
```
高度：40px（大）/ 32px（中）/ 24px（小）
内边距：16px 24px（大）/ 12px 16px（中）/ 8px 12px（小）
背景色：#4A90A4
文字颜色：#FFFFFF
圆角：8px
字体：14px Medium
悬停：背景色加深 10%
点击：背景色加深 20%
禁用：背景色 #CCCCCC，不可点击
```

**次要按钮（Secondary）**
```
背景色：透明
边框：1px solid #4A90A4
文字颜色：#4A90A4
悬停：背景色 rgba(74, 144, 164, 0.1)
```

**文字按钮（Text）**
```
背景色：透明
边框：无
文字颜色：#4A90A4
悬停：背景色 rgba(74, 144, 164, 0.1)
```

**危险按钮（Danger）**
```
背景色：#FF4D4F
文字颜色：#FFFFFF
```

## 四、关键页面详细设计

### 4.1 首页详细设计

#### 设计理念

首页是用户的第一印象，需要传达"温暖、专业、可信赖"的品牌形象。采用简洁的视觉层次，引导用户快速了解核心功能。

#### 视觉设计

**Hero Banner 区域**
- 背景图片：使用柔和的自然风景图片（如晨光、森林、湖泊），添加渐变遮罩
- 渐变遮罩：`linear-gradient(135deg, rgba(74, 144, 164, 0.85) 0%, rgba(124, 182, 157, 0.75) 100%)`
- 主标题：32px Bold，白色，居中
- 副标题：18px Regular，白色 80% 透明度
- CTA按钮：主按钮（温暖橙）+ 次要按钮（白色描边）

**功能入口区域**
- 4个功能卡片，等宽分布
- 图标：48px，主品牌色
- 标题：16px Medium，深灰色
- 描述：14px Regular，中灰色
- 悬停效果：卡片上浮 + 图标放大

**推荐内容区域**
- 左侧大卡片：宽度占比 50%，图片+标题+摘要
- 右侧小卡片：3列网格，仅显示图片+标题
- 滚动加载更多

#### 交互设计

1. **滚动动画**：页面元素随滚动渐入显示
2. **功能卡片悬停**：轻微上浮（translateY: -4px）+ 阴影增强
3. **CTA按钮**：悬停时颜色加深 + 轻微放大

---

### 4.2 AI助手对话页面详细设计

#### 设计理念

AI助手是用户情感倾诉的重要渠道，界面设计需要营造安全、私密、温暖的氛围。采用对话式UI，让用户感觉在与一个善解人意的朋友交流。

#### 视觉设计

**对话区域**
- 背景：柔和的渐变色 `linear-gradient(180deg, #F7F8FA 0%, #FFFFFF 100%)`
- AI消息气泡：浅灰背景 `#F5F5F5`，左对齐，圆角 `12px 12px 12px 4px`
- 用户消息气泡：主色背景 `#4A90A4`，白色文字，右对齐，圆角 `12px 12px 4px 12px`
- 时间戳：12px，浅灰色，显示在气泡下方

**AI头像设计**
- 尺寸：40px 圆形
- 形象：温和、友好的卡通形象
- 可选：显示"小驿"名称

**输入区域**
- 固定底部，高度 64px
- 输入框：圆角 24px，内边距 16px
- 发送按钮：圆形，主品牌色背景
- 支持语音输入（可选功能）

**快捷回复**
- 横向滚动的胶囊按钮
- 背景：浅灰，文字：主品牌色
- 点击后自动发送

#### 交互设计

1. **消息发送动画**：消息从底部滑入
2. **AI正在输入**：显示"..."动画
3. **长按消息**：复制、删除选项
4. **输入框聚焦**：边框高亮 + 轻微放大

#### 特殊功能

**情绪识别**
- AI自动识别用户情绪，在消息旁显示情绪标签
- 情绪标签：胶囊样式，不同颜色代表不同情绪

**资源推荐**
- AI可在对话中推荐相关文章、测评
- 推荐卡片：嵌入在对话气泡中

### 4.3 心理测评页面详细设计

#### 设计理念

测评页面需要营造专业、可信的氛围，同时降低用户的心理负担。清晰的进度指示和简洁的题目展示是关键。

#### 测评列表页设计

**筛选区域**
- 分类标签：横向滚动，选中状态使用主品牌色背景
- 搜索框：圆角输入框，带搜索图标

**测评卡片**
- 左侧：量表图标（48px）
- 中间：标题 + 描述 + 标签
- 右侧：评分、参与人数、开始按钮
- 悬停：卡片上浮 + 阴影增强

#### 测评详情页设计

**进度指示**
- 顶部进度条：高度 4px，主品牌色填充
- 文字提示："第 X 题 / 共 Y 题"

**题目区域**
- 卡片式布局，最大宽度 720px，居中显示
- 题目文字：18px Medium，深灰色
- 选项：单选按钮样式，选中时高亮

**选项设计**
```
默认状态：
┌─────────────────────────────────────┐
│  ○ 完全没有 (0分)                   │
└─────────────────────────────────────┘

┌─────────────────────────────────────┐

```

**导航按钮**
- 上一题：次要按钮，左侧
- 下一题：主要按钮，右侧
- 最后一题显示"提交"按钮

#### 测评结果页设计

**结果展示**
- 顶部：测评名称 + 完成时间
- 分数展示：大字号显示，配以颜色指示（绿色=正常，黄色=轻度，橙色=中度，红色=重度）
- 结果解读：分段展示，使用卡片样式
- 建议：专业建议 + 推荐资源

**操作按钮**
- 查看详细报告
- 分享给心理老师
- 预约咨询（可选）
- 返回首页

## 五、交互设计规范

### 5.1 动画规范

#### 过渡动画

| 类型 | 时长 | 缓动函数 | 用途 |
|------|------|----------|------|
| 快速 | 150ms | ease-out | 按钮状态变化 |
| 标准 | 250ms | ease-in-out | 弹窗显示/隐藏 |
| 慢速 | 400ms | ease-in-out | 页面切换 |

#### 常用动画

**淡入淡出**
```css
.fade-enter {
  opacity: 0;
}
.fade-enter-active {
  opacity: 1;
  transition: opacity 250ms ease-in-out;
}
```

**滑入滑出**
```css
.slide-up-enter {
  transform: translateY(20px);
  opacity: 0;
}
.slide-up-enter-active {
  transform: translateY(0);
  opacity: 1;
  transition: all 250ms ease-out;
}
```

**缩放**
```css
.scale-enter {
  transform: scale(0.95);
  opacity: 0;
}
.scale-enter-active {
  transform: scale(1);
  opacity: 1;
  transition: all 200ms ease-out;
}
```

### 5.2 反馈机制

#### 操作反馈

| 操作类型 | 反馈方式 | 示例 |
|----------|----------|------|
| 点击按钮 | 按钮状态变化 | 颜色加深 + 轻微缩放 |
| 提交表单 | 加载状态 + 结果提示 | 按钮 loading + Toast 提示 |
| 删除操作 | 确认弹窗 + 成功提示 | 二次确认 + 删除成功 |
| 错误提示 | 表单下方红色文字 | 输入框下方错误信息 |

#### Toast 提示规范

```
成功提示：绿色图标 + 白色背景 + 绿色边框
错误提示：红色图标 + 白色背景 + 红色边框
警告提示：橙色图标 + 白色背景 + 橙色边框
信息提示：蓝色图标 + 白色背景 + 蓝色边框

显示时长：2-3秒自动消失
位置：页面顶部居中，距顶部 80px
```
