## 一、项目概述

### 1.1 项目背景

随着社会压力的增加，心理健康问题日益突出。据统计，中国抑郁症患者超过9500万，大学生抑郁检出率达23.8%，而我国心理咨询师缺口达130万。传统的心理咨询模式存在以下问题：

- 心理咨询师稀缺，难以满足需求
- 心理问题污名化，患者不敢求助
- 心理问题隐蔽性强，早期难发现
- 缺乏持续的心理状态监测手段

### 1.2 项目目标

开发一个基于AI的心理健康检测与辅助系统，实现：

1. **早期筛查**：通过专业量表和AI分析，早期识别心理问题
2. **智能辅助**：提供AI心理助手，降低求助门槛
3. **持续监测**：建立心理档案，追踪心理状态变化
4. **预警干预**：智能预警机制，及时发现高风险用户

### 1.3 项目范围

| 范围 | 说明 |
|------|------|
| 用户群体 | 大学生、职场人士、关注心理健康的个人 |
| 应用场景 | 高校心理健康管理、企业员工关怀、个人心理健康管理 |
| 功能范围 | 心理测评、AI对话、情绪日记、知识库、预警系统 |
