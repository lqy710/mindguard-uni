## 一、业务背景

### 1.1 社会背景

近年来，随着社会节奏加快、竞争压力增大，心理健康问题日益突出，已成为影响公众健康的重要社会问题。

**数据支撑：**

| 指标 | 数据 | 来源 |
|------|------|------|
| 中国抑郁症患者 | 9500万+ | 国家卫健委 |
| 大学生抑郁检出率 | 23.8% | 中国大学生心理健康调查 |
| 青少年抑郁检出率 | 24.6% | 中国青少年心理健康调查 |
| 心理咨询师缺口 | 130万+ | 中国心理卫生协会 |
| 每10万人心理咨询师 | 2.2名 | 世界卫生组织标准：每10万人10名 |

### 1.2 政策背景

| 政策文件 | 发布时间 | 核心内容 |
|---------|---------|---------|
| 《健康中国2030规划纲要》 | 2016年 | 加强心理健康服务 |
| 《关于加强心理健康服务的指导意见》 | 2016年 | 构建心理健康服务体系 |
| 《全国精神卫生工作规划》 | 2015-2020年 | 完善精神卫生服务体系 |
| 教育部《学生心理健康管理》 | 2021年 | 高校按1:4000配备心理教师 |

### 1.3 行业现状

**现有解决方案的问题：**

| 问题 | 具体表现 |
|------|---------|
| 专业资源稀缺 | 心理咨询师数量不足，分布不均 |
| 服务门槛高 | 心理咨询费用高（300-1000元/次） |
| 污名化严重 | 心理问题被歧视，患者不敢求助 |
| 发现滞后 | 心理问题隐蔽性强，早期难发现 |
| 缺乏追踪 | 缺乏持续的心理状态监测手段 |

## 三、业务场景

### 3.1 核心业务场景

#### 场景一：大学生心理健康管理

```
场景描述：
├── 背景：某高校有2万名学生，心理中心仅有5名心理老师
├── 问题：无法全面了解学生心理状态，危机事件时有发生
├── 需求：建立学生心理健康档案，及时发现高风险学生
└── 方案：
    ├── 学生定期进行心理测评
    ├── 系统自动分析评估结果
    ├── 高风险学生自动预警
    └── 心理老师针对性干预
```

**业务流程：**

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│ 学生测评     │────▶│ AI分析评估   │────▶│ 风险预警     │────▶│ 老师干预     │
└─────────────┘     └─────────────┘     └─────────────┘     └─────────────┘
      │                   │                   │                   │
      ▼                   ▼                   ▼                   ▼
 完成量表           生成报告            推送预警            记录处理
 记录情绪           判定风险            通知相关人员         跟踪状态
```

#### 场景二：职场人士心理健康关怀

```
场景描述：
├── 背景：某互联网公司员工500人，工作压力大，离职率高
├── 问题：员工心理健康问题影响工作效率和团队稳定
├── 需求：关注员工心理健康，提供心理支持
└── 方案：
    ├── 员工使用AI助手倾诉压力
    ├── 记录情绪日记，追踪心理状态
    ├── 学习心理健康知识
    └── HR关注高风险员工
```

#### 场景三：个人心理健康管理

```
场景描述：
├── 背景：个人用户关注自身心理健康
├── 问题：缺乏便捷的心理健康工具，不知道如何了解自己的心理状态
├── 需求：便捷、私密、专业的心理健康服务
└── 方案：
    ├── 定期进行心理测评，了解心理状态
    ├── 记录情绪日记，追踪情绪变化
    ├── 与AI助手对话，获得情绪疏导
    ├── 学习心理健康知识，提升心理素质
```

### 3.2 用户使用场景

| 用户角色 | 使用场景 | 核心需求 |
|---------|---------|---------|
| **大学生** | 考前焦虑、学业压力、人际关系困扰 | 自我了解、情绪疏导、求助渠道 |
| **职场人士** | 工作压力、职业倦怠、人际冲突 | 压力释放、情绪管理、心理支持 |
| **学生家长** | 关注孩子心理健康、家庭教育困扰 | 了解孩子、学习知识、沟通技巧 |
| **心理老师** | 学生心理健康管理、危机干预 | 发现问题、预警通知、数据统计 |
| **HR/管理者** | 员工心理健康关怀、团队建设 | 员工关怀、数据分析、风险预警 |
