## 一、调研概述

### 1.1 调研目的

| 目的 | 说明 |
|------|------|
| 了解用户需求 | 了解目标用户对心理健康服务的真实需求 |
| 验证产品假设 | 验证产品功能设计的合理性 |
| 发现用户痛点 | 发现用户在心理健康方面的痛点和困扰 |
| 确定功能优先级 | 根据用户反馈确定功能开发优先级 |

### 1.2 调研对象

| 调研对象 | 样本量 | 调研方式 |
|---------|--------|---------|
| 大学生 | 100+ | 问卷调查 |
| 职场人士 | 50+ | 问卷调查 |
| 心理老师/咨询师 | 10+ | 深度访谈 |
| 学校管理者 | 5+ | 深度访谈 |

### 1.3 调研方法

| 方法 | 适用场景 | 优点 | 缺点 |
|------|---------|------|------|
| **问卷调查** | 大规模收集数据 | 样本量大、成本低、易分析 | 深度不够、回收率低 |
| **深度访谈** | 深入了解需求 | 深度高、灵活性强 | 样本量小、成本高 |
| **焦点小组** | 群体讨论 | 互动性强、观点丰富 | 组织难度大、易跑题 |
| **用户观察** | 观察实际行为 | 真实性强、发现隐性需求 | 成本高、样本量小 |

## 五、调研注意事项

### 5.1 问卷设计注意事项

| 注意事项 | 说明 |
|---------|------|
| 题目数量 | 控制在25题以内，填写时间10-15分钟 |
| 题目顺序 | 先易后难，敏感问题放后面 |
| 选项设计 | 选项互斥、穷尽，避免引导性 |
| 语言表达 | 简洁明了，避免专业术语 |

### 5.2 访谈注意事项

| 注意事项 | 说明 |
|---------|------|
| 访谈准备 | 提前了解访谈对象背景 |
| 访谈环境 | 安静、私密、舒适的环境 |
| 访谈技巧 | 倾听、追问、不引导、不评判 |
| 记录方式 | 征得同意后录音，及时整理笔记 |

### 5.3 伦理注意事项

| 注意事项 | 说明 |
|---------|------|
| 知情同意 | 告知调研目的、内容、用途 |
| 隐私保护 | 不收集个人身份信息，数据匿名处理 |
| 自愿原则 | 参与者可随时退出 |
| 数据安全 | 数据加密存储，仅用于项目研究 |

```
【问卷邀请】大学生心理健康需求调研

亲爱的同学：
    您好！
    我们正在进行一项关于大学生心理健康服务需求的调研，希望了解您对心理健康APP的真实需求和期望。您的回答将帮助我们设计更好的心理健康服务产品。
    
    问卷仅用于学术研究，不涉及个人隐私，大约需要10分钟填写。感谢您的参与！

    问卷链接：[链接]

    祝您学业顺利，生活愉快！
```

### 7.2 访谈邀请文案模板

```
【访谈邀请】心理健康服务需求调研

尊敬的[老师/专家]：
    您好！
    我们正在进行一项关于心理健康服务产品的研究，非常希望能听取您的专业意见。您在心理健康领域的丰富经验，对我们的研究具有重要价值。
    
    访谈大约需要30-45分钟，可以采用线上或线下的方式进行。访谈内容仅用于学术研究，我们将严格保密您的个人信息。
    
    如果您愿意参与，请回复您方便的时间，我们将根据您的安排进行访谈。
    
    感谢您的支持！
```
